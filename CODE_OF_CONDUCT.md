# Code of conduct

Be straightforward and assume the other person is too.

Concretely, in a repository like this one:

- **Argue about the thing, with reasons.** "This breaks byte compatibility with the Java library, here
  is the vector that fails" is a review. "This is wrong" is not.
- **Say when you do not know.** A question is cheaper than a wrong guess that reaches a client's
  database.
- **Disagreement about a technical decision is normal**, including with us. The contract exists so
  that those arguments can be settled with a test rather than with seniority.
- **No harassment, no personal remarks, no dragging in someone's identity or background.** It has
  nothing to do with whether the bytes match.

If someone is being harassed, or the above is not being honoured, email
**conduct@smartdataengines.com**. Reports are read by a person and answered.

Consequences, in order and used in order: a private word, a public correction, removal from the
repository.
